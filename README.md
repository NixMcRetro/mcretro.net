# McRetro.net

The source repository for [McRetro.net](https://mcretro.net), my long-running home on the web.

McRetro.net is a personal archive documenting the analog ghosts and digital debris of a life lived across both worlds.

It began with retro computers, game consoles, repairs and hardware experiments, but over time grew into something much broader: digital preservation, old websites, dial-up networking, development hardware, software archaeology, home servers, programming, security research, nature, personal projects and whatever else happened to become interesting along the way.

The archive currently spans material from 2012 onward, incorporating the earlier RetroJunkie.net project and fragments of personal websites that go back even further.

At its core, McRetro.net is about curiosity:

**Something interesting exists.  
I wonder how it works.  
There is probably only one way to find out.  
A project begins.**

## From hardware tinkering to digital preservation

The earliest McRetro material is heavily centred on retro hardware.

There are Sega Mega Drives, Saturns, Dreamcasts, TeraDrives, Amstrad Mega PCs, PlayStations, Super Nintendos, development systems, programmers, flash memory, broken power supplies and a truly unreasonable number of capacitors.

Over time the focus widened.

Rare hardware led to BIOS dumping and software preservation.

Old computers led to dial-up modems and experiments with period web browsers.

Dial-up led to rebuilding parts of the old web.

That led to projects involving GeoCities, archived forums, old personal websites, HTTP history, checksums, large-scale storage and long-term data integrity.

The same archival instinct later expanded into document recovery, forensic preservation, malware analysis and other projects where preserving the information became more important than preserving the physical machine.

In other words:

**Early McRetro preserves machines.  
Later McRetro preserves information.**

Both are still welcome here.

## Hardware archaeology

A large part of McRetro.net grew out of taking unusual hardware apart and trying to understand what made it work.

That has included:

- dumping the Japanese Sega Channel BIOS
- documenting Sega Saturn and Dreamcast development hardware
- preserving PlayStation development BIOSes
- repairing and modifying Sega TeraDrives
- experimenting with the Amstrad Mega PC and Mega PC Plus
- recovering data from old SCSI hard drives
- documenting prototype and development hardware
- identifying motherboard, optical-drive and power-supply revisions
- circuit bending consoles for completely sensible scientific reasons

Some projects succeeded immediately.

Many did not.

The failures are preserved too, because the path to the answer is often more useful than the answer by itself.

## Preservation and archival integrity

The preservation work gradually became more formal.

Later projects increasingly involve:

- cryptographic checksums
- verified copies of source data
- redundant storage
- ZFS and archival storage systems
- preserving original disk images before modifying hardware
- documenting provenance
- comparing independent extraction methods
- keeping original source material alongside transformed versions
- recording enough methodology that somebody else can reproduce the result

The goal is not merely to keep files.

The goal is to know what they are, where they came from, whether they changed, and how they were recovered.

## Historical preservation

A large part of McRetro.net is intentionally archival.

Old posts are not being rewritten into modern tutorials or made to pretend that I knew things in 2012 that I only learned years later.

Instead, the archive is progressively being reviewed to:

- correct demonstrable technical mistakes
- improve sourcing
- repair dead or damaged links where possible
- distinguish firsthand observations from assumptions
- add later context where technology has changed
- identify obsolete or unsafe instructions
- connect related multi-part projects
- preserve unsuccessful experiments and wrong turns
- retain the original humour, personality and historical setting

That last point matters.

The mistakes are part of the record.

A failed BIOS dump followed by another failed BIOS dump and eventually a successful BIOS dump tells a more useful story than quietly editing history so that everything apparently worked the first time.

## Technology

McRetro.net currently exists as a static site built with:

- [Jekyll](https://jekyllrb.com/)
- GitHub Pages
- GitHub Actions
- [Pagefind](https://pagefind.app/) for search
- custom HTML, CSS and Markdown

This is merely the latest incarnation.

Over the years the site has wandered through WordPress, Dropplets, FlatPress, Ghost, Jekyll, Raspberry Pis, different web servers and enough questionable architectural decisions that the website itself has effectively become one of the projects documented by the website.
