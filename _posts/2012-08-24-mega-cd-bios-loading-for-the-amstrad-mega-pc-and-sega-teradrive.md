EverDrive, is there anything you don't do? I've been thinking about getting an external Mega-CD running with either the Amstrad Mega PC or the Sega TeraDrive, and one of the first problems was how to load the Mega-CD BIOS. I originally thought I'd need an Action Replay or Datel CDX cartridge, but the Mega EverDrive can handle that side of things itself. The firmware even provides a dedicated CD BIOS mode and a Run CD function.

Of course, that doesn't magically connect a Mega-CD to either machine. I'd still need to work out how to get the expansion signals from the internal Mega Drive hardware to the external unit, which is an entirely different problem. Still, I've managed to solve the software side before creating the next headache. Excellent!
