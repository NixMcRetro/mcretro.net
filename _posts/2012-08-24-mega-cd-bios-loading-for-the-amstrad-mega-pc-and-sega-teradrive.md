EverDrive, is there anything you don't do?

This solves one half of an experiment I've been thinking about: getting the Amstrad Mega PC or Sega TeraDrive to work with an external Mega-CD. I had originally thought I would need an Action Replay or Datel CDX cartridge to provide the Mega-CD BIOS. The Mega EverDrive can run a Mega-CD BIOS from the cartridge slot instead, which makes the software side considerably easier. The 2012 Mega EverDrive firmware even includes a dedicated CD BIOS mode and a Run CD function.

That does **not** magically attach a Mega-CD to either machine.

The Mega-CD hardware still has to be physically connected to the Mega Drive expansion signals inside the Mega PC or TeraDrive. The EverDrive only helps with the BIOS-loading side of the experiment.

Still, one problem solved before I've even created the next one.
