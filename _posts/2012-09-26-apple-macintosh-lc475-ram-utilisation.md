Found that this machine was still using 24-bit addressing. With 36MB installed, that made most of the additional memory effectively unavailable to applications, and the Finder presented a huge apparent System allocation. I turned on 32-bit addressing via the Memory control panel and the extra RAM became usable normally, with the reported System footprint dropping back to around 2MB. I knew System 7 wasn't THAT hungry for RAM.

Found out about this thanks to [MicroMac](https://www.micromac.com/FAQ/faq_lc475_upgrade.html).
