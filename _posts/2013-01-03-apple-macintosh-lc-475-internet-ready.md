This is on the old Apple Macintosh LC 475 (aka Performa 475) running Mac OS 7.6.1. Works pretty well given the age of the thing. For this sort of light web browsing it felt roughly comparable to using one of my 486 DX2-66 systems. Even the versions of Netscape are pretty much the same as the 486 Windows versions.

I'd definitely recommend sticking to a more modern operating system if you are looking for a fully featured web browsing experience.
