The old LC 475 is officially internet ready.

I'm running Mac OS 7.6.1 and using the PDS Ethernet card I picked up last year.

The LC 475 did not include onboard Ethernet, but Apple provided an LC III-style PDS expansion slot, which makes adding a network card straightforward once you actually find one.

{% include youtube.html id="tFf12tlTIvw" %}

For light period web browsing it works surprisingly well.

Subjectively, it feels somewhere around the same general level as browsing on one of my 486DX2-66 systems.

Even the Netscape experience is fairly similar.

Obviously this is not the machine to choose if you want anything resembling a fully featured modern web browser.

But getting a 68K Macintosh onto the network and browsing the web at all?

I'll take it.
