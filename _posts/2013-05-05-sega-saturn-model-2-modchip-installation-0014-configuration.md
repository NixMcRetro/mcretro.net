Here's a Japanese Model 2 Saturn that needed a modchip, so I went ahead and installed one. This particular console and modchip combination uses the `0014` configuration.

{% include youtube.html id="iveyeLJkNAg" %}

The important word there is **particular**. Model 2 Saturns were produced with different CD-drive boards and controller arrangements, and modchip installation details vary between them. `0014` is a setting used by this style of modchip. It should not be treated as a universal configuration for every 21-pin Saturn. Identify the CD hardware inside the console before copying an installation intended for another revision.
