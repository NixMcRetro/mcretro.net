VBT over at ASSEMblergames has been working on getting Wolfenstein 3D running on the Sega Saturn.

More specifically, this is early Saturn support for Wolf4SDL.

{% include youtube.html id="9Rxxr97mrdE" %}

This build seemed to work in emulators, but I could not get it behaving properly on my actual hardware.

Apparently it was expected to work, which left me wondering whether the strange development hardware I was using had something to do with the problem.

I never established that.

So the useful historical result here is simply that this early 2013 build did not work correctly on my setup, while the exact cause remained unresolved.

Keep up the good work and I'll be playing W3D in no time!

VBT continued developing the Saturn port after this experiment.

In December 2023, VBT explicitly described this old version as deprecated and pointed users towards the newer project.

So the video above is best viewed as a snapshot of the port during its early development rather than representative of where the Saturn version eventually ended up.
