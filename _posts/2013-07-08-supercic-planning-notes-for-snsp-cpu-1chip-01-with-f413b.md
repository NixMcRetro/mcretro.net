This will be the article on how to install SuperCIC for switchless region-free gaming. Provided I can find the time. The board shown is an `SNSP-CPU-1CHIP-01` with an `F413B` lockout chip at U8.

This particular article never became the full installation guide I had planned. Wolfsoft's linked example uses an F413A board with separate PPU chips, so it is not a pin-for-pin wiring guide for this 1CHIP board. Disabling the original CIC and installing SuperCIC are different procedures; this placeholder does not document the complete wiring for either. Later installation work is linked below.
