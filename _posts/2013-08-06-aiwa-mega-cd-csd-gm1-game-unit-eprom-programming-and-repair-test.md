The Aiwa Mega-CD BIOS is finally going back onto hardware.

I had already dumped and preserved the original MPR-15768-T BIOS, then fitted a socket and repaired the damaged traces around the Game Unit ROM area.

Now it is time to blank an EPROM, program it with the preserved BIOS image and see whether all that earlier repair work actually functions as intended.

This is really testing several things at once:

- whether the replacement EPROM can be programmed successfully;
- whether the new socket is making proper contact;
- whether the repaired PCB traces are intact;
- whether the Game Unit can actually use the programmed BIOS.

If it works, that is a rather satisfying amount of earlier damage finally undone.

Watch on to find out whether the news is good!
