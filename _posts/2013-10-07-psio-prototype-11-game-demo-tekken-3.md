Time to give Tekken 3 a go on the PSIO prototype! I've got the Systems Console running on the PC, so I'll select Tekken from the game list and see how far we get. Hardware 1.1, software 1.1A, and a perfectly good PlayStation waiting to be entertained.

The image starts loading and we get some initial activity, which is encouraging. Unfortunately, that's about as far as I've managed to get Tekken 3 to go. I can press Start and hear a little sound effect, but the game doesn't progress into anything I can actually play.

Well, that was a quick test! I suppose the other game demonstrations will be rather easy to record if they all behave like this. Just kidding. There's plenty more to try, and this is still very early prototype hardware.

Please remember that these results apply to the PSIO 1.1 hardware and 1.1A software, not later versions or the final product. You can hit up [ps-io.com](https://ps-io.com/) if you have any questions, since I'm but a mere tester. I don't understand the technology behind this wonderful invention!

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- PlayStation: SCPH-5502
- CD deck: removed
