Tekken 3 does not get very far on this early PSIO 1.1 setup.

That was not the end of the story.

I returned to Tekken 3 in November with a newer debug bootloader and got considerably further.

At that point I recorded that an updated bootloader could make the game work, which is a good illustration of why these prototype videos should not be read as permanent compatibility verdicts.

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- PlayStation: SCPH-5502
- CD deck: removed

This video records how Tekken 3 behaved on this particular early build.

Later prototype software behaved differently.
