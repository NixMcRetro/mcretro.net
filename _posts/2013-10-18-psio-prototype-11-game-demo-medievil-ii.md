MediEvil II is next up on the PSIO prototype testing list. I was originally hoping to use a PAL version for some additional compatibility testing, but I could only find the American NTSC version for this demonstration. Never mind, let's see what happens!

The game loads, which is always a promising start, although the audio is missing. That's a bit of a disappointment, but sound support is still incomplete in this early prototype, so it isn't entirely unexpected.

Before long I'm wandering around the game's rather gloomy version of London, trying to work out where I'm supposed to be going. I've got a sword, there's a museum to explore and plenty of strange things waiting to cause trouble. So far, the gameplay seems to be working reasonably well.

Unfortunately, there is a rather noticeable problem when I interact with the ghostly sequence. During my earlier test, the game became stuck at that point, and it does much the same thing here. It can sit there for several minutes before showing any more activity, and even then the controls and progression don't seem to recover properly.

If I avoid that particular interaction, I can continue further into the game. So MediEvil II isn't a complete failure on the prototype, but it certainly isn't running perfectly either. Missing audio and an awkward lockup are enough to put it on the list for further investigation.

Please remember that these results apply to PSIO hardware 1.1 and software 1.1A. It's still a prototype, and I'm just recording what works and what doesn't on this particular setup.

You can hit up [ps-io.com](https://ps-io.com/) if you have any questions, since I'm but a mere tester. I don't understand the technology behind this wonderful invention!

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- PlayStation: SCPH-5502
- CD deck: removed
