Resident Evil! Famous for its wonderful B-grade voiceovers, and now it's time to see whether it'll run on this PSIO prototype. I've got the original PlayStation game ready to go, so let's fire it up and see what happens.

Unfortunately, the first attempt doesn't look particularly encouraging. The game doesn't seem to connect or start properly, so I gave the PlayStation a reboot and tried again. That got me a little further, although the picture was considerably darker than I remembered Resident Evil being.

I left it for a while to see whether anything useful would happen, but there wasn't much progress. Another reboot didn't improve things either. It's a shame, because I was rather hoping to hear some of those delightful voiceovers!

So Resident Evil isn't functional in this particular test. No worries, though, because this is still prototype hardware and version 2.0 of PSIO is on the horizon. I've got a good feeling about what's to come! :)

These results apply to hardware 1.1 with software 1.1A, not later revisions or the final product. You can hit up [ps-io.com](https://ps-io.com/) if you have any questions, since I'm but a mere tester.

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- PlayStation: SCPH-5502
- CD deck: removed
