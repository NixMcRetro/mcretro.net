Tekken 3 gets considerably further with this debug bootloader than it did in my earlier PSIO test.

I had also been told that an updated bootloader could make the game work.

The important distinction is that **this video itself does not demonstrate complete Tekken 3 compatibility**.

It demonstrates that changing the prototype bootloader changed the result and substantially improved how far the game progressed.

That is exactly why the earlier Tekken 3 failure should not be treated as a permanent compatibility verdict.

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- debug bootloader
- PlayStation: SCPH-5502
- CD deck: removed
