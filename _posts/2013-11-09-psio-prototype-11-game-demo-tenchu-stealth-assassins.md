Next up on the PSIO prototype test bench is Tenchu: Stealth Assassins. I've already got the PlayStation switched on, so we're one step ahead of ourselves for a change. Let's find the game in the list and see what happens!

The opening sequence starts playing, but there's no sound to accompany it. That's a bit disappointing, particularly for a game with such a dramatic introduction. I tried moving past the video to see whether we'd reach the main menu, but instead I ended up staring at a blank screen.

No worries, let's give it another go. I rebooted the PlayStation and loaded Tenchu again, this time letting the introduction play through to see whether it would behave any differently. The video itself was certainly doing something, even if the audio was still missing.

Unfortunately, the result was much the same. We got through the introduction and then the game stopped progressing. I was rather hoping to get some actual ninja action out of this one, but apparently that's going to have to wait.

So Tenchu isn't functional beyond the introductory video in this particular test. Still, PSIO is early prototype hardware, and version 2.0 is already in development. I'm looking forward to seeing how things improve.

These results apply to PSIO hardware 1.1 with software 1.1A. For updates and more information, head over to [ps-io.com](https://ps-io.com/).

**Prototype test conditions**

- PSIO hardware: 1.1
- PSIO software: 1.1A
- PlayStation: SCPH-5502
- CD deck: removed
