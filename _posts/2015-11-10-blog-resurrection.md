The blog came back to life and was extinguished again within a week or so. [Dropplets](https://web.archive.org/web/20151104110559/http://dropplets.com:80/) just doesn't do what I want it to. I'm sure if I messed about with the code enough it probably would have... Where does that leave this blog? **[FlatPress!](https://www.flatpress.org/)**

![](/assets/images/2015/img_0442.jpg)

I'll have more on FlatPress and the plugins I've used to make the site functional. It's been quite an experience, from modifying Python scripts to salsa dancing.

After plenty of tinkering, the blog is finally at a point where it is actually functional. The sidebar search even works. Doesn't fare too badly on Netscape either.

This is currently running on a Raspberry Pi 2. I was considering moving it back to the Raspberry Pi Model A+ once I was confident I could retire the old WordPress database. On this little Raspberry Pi setup, WordPress plus MySQL felt much heavier than I wanted, which is why I kept experimenting with flat-file blogging software.

I'm looking forward to fixing all the broken imported posts. For now they live under the temporary Imported category. Once each one is cleaned up, it can move into the correct category and disappear from the list of things to do. I'll also need to import all the newer YouTube videos. Oh, and work out how to get images into this blog editor!

What a busy time ahead. Stay tuned! ;)
