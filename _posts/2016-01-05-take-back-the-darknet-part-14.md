**Part 14 - Testing the Waters**

**Archive note:** This page documents the January 2016 Tor v2 onion-service setup. Read the compatibility and security warning in [Part 1](/take-back-the-darknet-part-1/) before using these commands on a current system.

Time to get some content onto the web server.

In this setup I could either use the Samba share configured earlier or create files directly from the terminal.

Create a simple `index.html` with Notepad, TextEdit, Nano or another text editor and place it in the website directory.

To see the onion address generated for this historical service:

`sudo cat /var/lib/tor/website1/hostname`

Opening that address in Tor Browser should then display the test page.

Remember that the address generated by this 2016 setup is a version 2 onion address. Those addresses no longer work on the modern Tor network.
