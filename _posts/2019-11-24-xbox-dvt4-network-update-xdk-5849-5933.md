We bring the DVT4 from the 5849 recovery image to the 5933 build I had available at the time. I originally described 5933 as the "latest available XDK" because it had the higher build number, but the surviving XDK history is messier than that. XDK 5849 is generally documented as the final official developer release, while 5933 appears in later archival references as an uncertain or internal build. So this video records the update path I actually used rather than establishing Microsoft's release chronology.

I also couldn't get the update process working from Windows 10, while Windows 7 running under Parallels on the Mac worked perfectly for this setup. That is what worked for me here, not a universal requirement that every 5933 update needs Windows 7. Sure is great to see this stuff still working all these years later!
