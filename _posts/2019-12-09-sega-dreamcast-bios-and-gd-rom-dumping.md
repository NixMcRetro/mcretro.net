Creating backups of your Dreamcast BIOS and GD-ROMs has never been so easy, provided you have a Broadband Adapter and `httpd-ack`. Configure the BBA's network settings first, then run `httpd-ack` and open the Dreamcast's IP address in a web browser on another machine on the same network. From there you can download the BIOS or individual GD-ROM tracks. Just don't get lost in the menus like I did in the first video. XDP v7 Browser solved that problem for me, maybe it will for you too?
