I've been working on dialling up on a MiSTer since April 2021. In the longer term I knew I would need websites that were small enough to browse using an old web browser. Enter [GeoCities](https://web.archive.org/web/19961022173245/http://www.geocities.com/). Deleted by Yahoo in 2009, [Archive Team](https://wiki.archiveteam.org/index.php/GeoCities_Project) saved a fair chunk of it. It's not all there but it's better than the absolutely nothing Yahoo has on offer.

As it happened [RetroChallenge](https://www.retrochallenge.org) 2021/10 was running, so in the 11th hour I threw my hat into the (web)ring. For the past several weeks I've been keeping [a blog of my progress](https://forum.acms.org.au/t/geocities-rebuild-for-older-browsers/83) on the newly launched Australian Computer Museum Society (ACMS) forum.

One of the less glamorous jobs has been removing all the static directory index pages left behind in the archive. There were around 220,000 of the things! I'd run a test first, but deleting that many files still makes me nervous. The plan is to generate the directory listings dynamically instead, so the site behaves a little more like the old web. The archive itself is split across the main GeoCities neighbourhoods, files waiting to be merged and various bits I'm still sorting out, including the wonderful mess caused by case-sensitive directory names.

This has made things progress a lot faster than expected. I hadn't planned on starting this part of the project until next year. Yet here we are. Now I can browse the old internet through real modems connected to a MiSTer running Windows 98.

You can check out the 56k friendly GeoCities at [http://geocities.mcretro.net](/homepages/geocities). There's still a lot of work going on in the backend. Expect trouble! 🎃
