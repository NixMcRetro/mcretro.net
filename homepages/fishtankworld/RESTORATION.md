# Fish Tank World historical restoration

Source: owner-provided PHP-based Fish Tank World archive in Google Drive. Original HTML and prose are preserved; PHP includes are compiled to static HTML and paths to the original profile and image content now point under /homepages/fishtankworld/. The original historical image counter is decorative rather than functional.

The old GIF and JPEG files are retained as historical assets. The PHP-based Stuporglue/InstaGallery photo viewer is replaced with a static gallery showing archived photographs; GitHub Pages cannot execute PHP.
