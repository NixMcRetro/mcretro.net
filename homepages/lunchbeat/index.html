Eight steps. Four sounds. Endless fun.

Press ENABLE AUDIO first. Hit PLAY, then EDIT to choose a step. The four instrument buttons toggle sounds on that step. The eight blue LEDs mirror the original dual-purpose display, using brightness to show the selected step.

About this recreation. The synthesiser logic is adapted from Jan Cumpelik's Lunchbeat PCB v1.31 C firmware (2013–2014) and aims to recreate its four 1-bit voices, 3-bit summed output, original eight-step sequencing and edit/setup controls. This is a browser emulation, not a cycle-accurate AVR or analogue circuit simulation; your browser's audio hardware and filtering will sound somewhat different. The visually inspired PCB is an original HTML/CSS illustration, not the original manufacturing artwork. Sound-algorithm port: GPL-3.0, with author attribution preserved; hardware design by Jan Cumpelik, CC BY-SA 3.0. Original PCB repository ↗ · GPL v3 ↗. Everything runs locally; no samples, server or external JavaScript needed.
